# M&A Gifts

A luxury gift boutique offering elegant gift boxes, beauty & skincare products, perfumes, accessories, and personalized gifts. Thoughtfully curated to suit every taste, occasion, and budget. Made with Love, Just for You. ❤️

## Preview environment

The `feature/customer-auth-cart` branch is configured for an isolated Cloudflare Pages preview. Production deployments are disabled for this preview project. The preview is for visual review only until secure order creation, payment, and inventory validation are completed.
